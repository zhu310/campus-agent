# 评测报告

本文档用于记录项目主链路的验收结果。当前先建立评测框架，后续代码稳定后补充真实测试数据、截图和结论。

## 1. 评测目标

验证智审通 Campus Copilot 是否能稳定完成高校事务办理核心闭环：

```text
规则/模板上传 -> RAG 问答 -> 材料解析 -> 字段抽取 -> 审核并补全 -> 表单草稿 -> 办理清单 -> 会话留痕
```

重点指标：

- 端到端主链路是否跑通
- RAG 回答是否有依据
- 字段抽取是否准确
- 审核结论是否可解释
- 表单预填是否可用
- 待办步骤是否合理
- 现场演示是否稳定
