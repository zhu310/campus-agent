# Golden Dataset 设计

本文档用于规划项目评测数据集。当前先建立样本结构和第一批示例，后续根据最终代码效果补充到 50-100 组。

## 1. 数据集目标

Golden Dataset 用于验证系统在高校事务办理场景中的稳定性：

- RAG 问答是否基于制度依据
- 字段抽取是否准确
- 审核结论是否符合规则
- 表单预填是否正确
- 待办生成是否合理

## 2. 样本格式

建议每条样本包含：

| 字段 | 说明 |
|---|---|
| `id` | 样本编号 |
| `task_type` | 任务类型，如 `rag_qa`、`field_extract`、`audit`、`form_prefill`、`workflow_plan` |
| `scenario` | 场景，如比赛报名、请假、报销、奖助学金 |
| `input` | 用户问题或材料文本 |
| `expected` | 黄金标准输出要点 |
| `evidence` | 依据片段或规则 |
| `status` | 是否已实测 |

## 8. 扩展样本规划

后续可扩展场景：

- 请假申请
- 报销申请
- 奖助学金材料审核
- 社团活动审批
- 科研立项材料审核

每个场景建议至少准备：

- 5 条 RAG 问答
- 3 条字段抽取
- 3 条规则审核
- 2 条表单预填
- 2 条工作流规划

达到 5 个场景后，可形成约 75 条样本；再补充边界条件即可达到 100 条。
